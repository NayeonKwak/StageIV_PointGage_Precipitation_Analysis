# Gridded and Point-Gage Precipitation in Urban Watersheds

This repository contains processed data and Python code supporting the manuscript:

 **Similar Totals, Different Storm Structures: Comparing Gridded and Point-Based Precipitation Data for Watershed Hydrologic Analysis** **

The study compares watershed-average NCEP Stage IV precipitation with point-gage precipitation across urban watersheds in Austin, Texas; Atlanta, Georgia; and Philadelphia, Pennsylvania.

## Current repository contents

- `code/`: Python scripts used for data processing, analysis, statistical testing, and figure generation.
- `data/`: Processed precipitation, streamflow, event-level, annual-summary, spatial-mask, and statistical-results files.
- `documentation/`: Detailed documentation is being finalized and will be added in the next repository version.

## Study period

Water Years 2018–2025.

## Data availability

The repository contains processed study products. The complete original national Stage IV archive is not redistributed. Original source datasets are identified in the manuscript and will be described fully in the repository documentation.
